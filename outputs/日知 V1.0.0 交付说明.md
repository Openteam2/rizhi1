# 日知 V1.0.0 改造交付说明

## 一、变更摘要

- 日记卡片统一了日期、农历、标题、摘要和标签的字号、行高、间距与截断规则。
- 每日壁纸支持独立保存位置、遮罩、模糊和调性，不再复用 Banner 参数。
- 新增元信息、搜索、统计、更新检查四类 API。
- 设置页新增“关于”，展示原作者、版本、投稿邮箱、运行环境和仓库信息。
- 更新检查支持 GitHub Release、远端 `package.json` 版本和最新提交三层降级。
- GitHub Token 只通过环境变量或 `.env` 读取，不返回浏览器，不写入数据库和仓库。
- 新增网站 favicon、PWA、Apple Touch Icon 和 Windows 桌面快捷方式图标。

## 三、日记卡片布局

改动前：

- 日期、农历、标题、摘要和标签字号接近，主次不明显。
- 长标题和摘要直接截断，标签容易与正文拥挤。
- 壁纸层可能盖住遮罩，调整参数后看不到视觉效果。

改动后：

```css
.puzzle-grid {
  --tile-meta-size: 8.5px;
  --tile-title-size: 11px;
  --tile-summary-size: 10.75px;
}

.tile-note-title {
  line-height: 1.45;
  -webkit-line-clamp: 1;
}

.tile-note-summary {
  line-height: 1.55;
  -webkit-line-clamp: 2;
}
```

- 日期和农历使用等宽字体，标题使用无衬线粗体，摘要使用衬线正文。
- 标题保持一行，摘要最多两行，均允许中文自然换行并使用省略号。
- 标签固定在底部，正文预留底部空间，不再与标签重叠。
- 壁纸使用独立图片层，先模糊图片，再叠加可调遮罩，最后渲染文字。
- 宽度低于 1080px 时统一缩小字号和行高，不改变对齐规则。

关键实现位于 `public/styles.css` 的 `.puzzle-grid`、`.tile-wallpaper-layer`、`.tile-note-title` 和 `.tile-note-summary`。

## 四、每日壁纸独立参数

每条记录独立保存：

```json
{
  "wallpaperPosition": { "x": 68, "y": 30 },
  "wallpaperStyle": {
    "overlay": 78,
    "blur": 5,
    "tone": "none"
  }
}
```

- 位置：0～100%。
- 遮罩：0～90%。
- 模糊：0～14px。
- 调性：`none`、`mono`、`cool`、`warm`。

保存接口：

```http
PUT /api/notes/:date/wallpaper
```

```json
{
  "assetId": "已有图片 ID",
  "positionX": 68,
  "positionY": 30,
  "overlay": 78,
  "blur": 5,
  "tone": "mono"
}
```

## 五、新增 API

### 1. 应用元信息

```http
GET /api/meta
```

主要返回字段：

```json
{
  "name": "日知",
  "version": "1.0.0",
  "author": "椿与岸",
  "email": "L671456971@gmail.com",
  "repository": "https://github.com/Openteam2/rizhi1",
  "nodeVersion": "v24.20.0",
  "updateCheck": {
    "tokenConfigured": false,
    "authMode": "anonymous"
  }
}
```

### 2. 搜索记录

```http
GET /api/search?q=风格&tag=AI短片&start=2026-11-01&end=2026-11-30&limit=20&offset=0
```

| 参数 | 必填 | 校验 |
| --- | --- | --- |
| `q` | 否 | 最多 100 字符 |
| `tag` | 否 | 最多 20 字符 |
| `start` | 否 | `YYYY-MM-DD` |
| `end` | 否 | `YYYY-MM-DD`，不得早于 `start` |
| `limit` | 否 | 1～100，默认 20 |
| `offset` | 否 | 0～10000，默认 0 |

返回：

```json
{
  "items": [],
  "total": 0,
  "limit": 20,
  "offset": 0
}
```

错误码：`INVALID_QUERY`、`INVALID_TAG`、`INVALID_DATE`、`INVALID_DATE_RANGE`、`INVALID_LIMIT`、`INVALID_OFFSET`。

### 3. 学习统计

```http
GET /api/stats?month=2026-11
```

返回记录数、正文字符数、AI 提炼数、附件数、标签排行和每日字符分布。

错误码：`INVALID_MONTH`。

### 4. GitHub 更新检查

```http
POST /api/update/check
Content-Type: application/json

{}
```

返回：

```json
{
  "ok": true,
  "status": "current",
  "currentVersion": "1.0.0",
  "latestVersion": "1.0.0",
  "hasUpdate": false,
  "source": "release",
  "tokenConfigured": true,
  "latestCommit": null
}
```

检查顺序：

1. GitHub 最新 Release 标签。
2. 无 Release 时读取远端 `package.json` 版本。
3. 以上均无版本时返回最新提交，并将 `hasUpdate` 设为 `null`，由用户手动判断。

成功结果缓存 10 分钟，避免重复消耗 GitHub API 限额。

## 六、GitHub Token 配置

复制环境变量模板：

```powershell
Copy-Item .env.example .env
```

在 `.env` 中设置：

```text
GITHUB_TOKEN=your_token_here
GITHUB_REPOSITORY=Openteam2/rizhi1
GITHUB_DEFAULT_BRANCH=main
```

也可以仅在当前 PowerShell 会话设置：

```powershell
$env:GITHUB_TOKEN="your_token_here"
npm start
```

`.env` 已被 `.gitignore` 忽略。Token 只存在于本地服务进程，不会返回浏览器。

未配置 Token 时，应用仍会访问公开仓库。若匿名配额耗尽、网络不可用或仓库无权访问，接口返回 `UPDATE_CHECK_UNAVAILABLE`，关于页显示失败原因和“手动查看仓库”入口。
