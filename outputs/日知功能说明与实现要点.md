## 1. DeepSeek 连接修复

### 根因

当前配置使用了 `deepseek-flash`，它不是 DeepSeek 官方对话 API 的模型名称。官方 `/chat/completions` 接口应使用：

```text
Base URL：https://api.deepseek.com
模型：deepseek-chat
推理模型：deepseek-reasoner
```

同时，旧服务进程启动时网络权限尚未放开，导致首次连通测试返回网络错误。新版服务已切换为服务端代理请求，不再受浏览器 CORS 限制。

### 关键修复

- 服务端代理 DeepSeek 请求，浏览器不直接访问第三方接口。
- 自动规范化完整接口地址，例如粘贴 `https://api.deepseek.com/chat/completions` 也不会重复拼接路径。
- DeepSeek 预设只接受 `deepseek-chat` 或 `deepseek-reasoner`，错误模型自动纠正。
- 不发送部分模型不支持的 `response_format` 和 `temperature` 参数。
- 网络错误、HTTP 408/429/5xx 最多退避重试两次。
- 增加“测试连接”，显示实际模型与响应延迟。
- API Key 使用 AES-256-GCM 加密保存在本地。

### 核心请求代码

```js
// server.mjs
const endpoint = `${normalizeBaseUrl(config.baseUrl)}/chat/completions`;
const requestBody = {
  model: config.model,
  messages,
  stream: false,
};

// deepseek-reasoner 不支持部分采样参数，因此按模型省略。
if (!/^deepseek-reasoner/i.test(config.model)) {
  requestBody.temperature = 0.2;
}

const response = await fetch(endpoint, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    Authorization: `Bearer ${config.apiKey}`,
  },
  body: JSON.stringify(requestBody),
  signal: AbortSignal.timeout(120_000),
});
```

重试策略：

```js
const maxRetries = 2;
for (let attempt = 0; attempt <= maxRetries; attempt += 1) {
  try {
    // 发起请求
  } catch (error) {
    if (attempt < maxRetries) {
      // 500ms、1000ms 指数退避
      await sleep(500 * 2 ** attempt);
      continue;
    }
    throw new Error("网络请求失败，已自动重试");
  }

  if (response.status === 429 || response.status >= 500) {
    // 仍可重试时等待后继续
  }
}
```

## 2. 日历图片展示区

日历上方新增图片区，显示：

- 大号当天日期
- 星期
- 农历日期
- 干支年份
- 二十四节气
- 今日学习摘要

月度拼图中的每个日期格也显示农历日期；节气当天优先显示节气名称。

图片区支持在“设置 → 外观与标签”中调整：

- 本地图片上传、更换、移除
- 晨雾玻璃、浅色纸张、深色电影三种风格
- 紧凑、标准、舒展三种高度
- 图片焦点位置
- 遮罩强度

农历使用浏览器原生 Chinese Calendar，节气使用离线 24 节气算法，不依赖网络。

配置数据结构：

```json
{
  "hero": {
    "style": "glass",
    "height": "standard",
    "overlay": 38,
    "positionX": 50,
    "positionY": 50
  }
}
```

图片文件保存在 `data/assets/`，数据库只保存元数据和图片 ID。

## 3. 外观、动画和自定义标签

设置页包含：

- 正文字体：衬线、无衬线、等宽
- 字号：13～24px
- 行距：1.5～2.4
- 页面点击与切换平滑过渡开关
- 最多 30 个系统自定义标签

平滑过渡关闭时，根节点增加 `.no-motion`，统一禁用 transition 和 animation：

```css
html.no-motion *,
html.no-motion *::before,
html.no-motion *::after {
  animation-duration: 0.01ms !important;
  transition-duration: 0.01ms !important;
}
```

自定义标签会作为编辑器输入建议出现，并在标签筛选菜单中参与筛选。

## 4. 删除学习记录

记录详情新增删除按钮。确认后，服务端会删除：

- 当日正文、标签、AI 提炼结果
- 当日附件和录音元数据
- 对应附件文件

接口：

```http
DELETE /api/notes/:date
```

关键代码：

```js
const assets = selectAssetsForNote.all(date);
deleteAllNoteAssets.run(date);
deleteNoteRow.run(date);
await Promise.all(assets.map(deleteAssetFile));
```

## 5. 文本复制、替换与 AI 润色

编辑器工具栏提供：

- 复制选中文字
- 未选择时复制全文
- 查找并替换单处
- 全部替换
- 按“清楚 / 简洁 / 专业 / 学术”风格润色

AI 润色接口：

```http
POST /api/ai/polish
Content-Type: application/json

{
  "text": "需要润色的原文",
  "style": "concise"
}
```

返回：

```json
{
  "text": "润色后的文字",
  "style": "concise",
  "model": "deepseek-chat",
  "generatedAt": "2026-11-07T00:00:00.000Z"
}
```

润色结果先展示预览，用户确认后才替换正文或选区，不会直接覆盖原内容。

## 6. 文件插入

编辑器点击“文件”：

1. 当前正文有修改时先自动保存。
2. 文件转为本地数据并上传至服务端。
3. 文件保存到 `data/assets/`。
4. 正文光标位置自动插入链接。
5. 详情页和编辑器均显示附件列表。

单个文件上限 10MB。

```http
POST /api/notes/:date/assets

{
  "name": "notes.pdf",
  "mimeType": "application/pdf",
  "kind": "attachment",
  "data": "data:application/pdf;base64,..."
}
```

## 7. 文本录音

编辑器点击“录音”：

1. 浏览器请求麦克风权限。
2. MediaRecorder 将音频保存在本地。
3. 浏览器支持 Web Speech API 时同步转写中文。
4. 停止后上传录音附件。
5. 转写文字和录音链接插入正文。
6. 自动保存当天记录。

若浏览器不支持实时转写，仍会保存完整录音文件。

录音文件与附件由应用保存在本机；实时转写使用浏览器提供的 Web Speech API，部分浏览器可能将音频交给其自身的在线语音服务。只有用户在编辑器主动点击“润色”或“提炼”时，对应文本才会发送给配置的 AI 模型。
